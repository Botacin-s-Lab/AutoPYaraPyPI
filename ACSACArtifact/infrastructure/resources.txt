================================================================================
Execution environment: requirements and expected resource use
================================================================================

--------------------------------------------------------------------------------
1. HARDWARE REQUIREMENTS
--------------------------------------------------------------------------------

    RAM         16 GB minimum, 24 GB recommended.   <-- the binding constraint
    Disk        ~2 GB free (600 MB Bloom filter data, plus dependencies)
    CPU         Any x86-64 processor; 4+ cores recommended
    Network     Required during install.sh (~600 MB download)
    GPU         Not used

The RAM figure is the one that matters. The JVM backend is started with a fixed
14 GB maximum heap, which is not configurable in the current release. A machine
with less than 16 GB of physical RAM risks the operating system terminating the
process partway through a run. See constraints.txt.

Reference platform used for our own verification:

    Ubuntu Linux, x86-64, 27 GB RAM, OpenJDK 21, CPython 3.9-3.12

--------------------------------------------------------------------------------
2. SOFTWARE REQUIREMENTS
--------------------------------------------------------------------------------

    OS          Linux (tested); macOS and Windows untested
    Python      3.9 - 3.12
    Java        JRE 11 or newer, on PATH or via JAVA_HOME
                (verified against OpenJDK 17 in CI and OpenJDK 21 locally)

Python dependencies are installed by install.sh and pinned in
../artifact/requirements-lock.txt. A Dockerfile is provided in the parent
directory if you would rather not install into the host environment.

--------------------------------------------------------------------------------
3. PUBLIC INFRASTRUCTURE
--------------------------------------------------------------------------------

This artifact runs on public research infrastructure. Recommended platforms,
both of which provide bare-metal nodes comfortably exceeding the RAM
requirement:

    CloudLab     https://www.cloudlab.us/       any standard x86-64 node
    Chameleon    https://www.chameleoncloud.org/ any standard compute node

Google Colab is NOT suitable - see constraints.txt for the reason.

No special hardware, licensed software, or institutional access is needed.
Everything the artifact depends on is publicly downloadable.

--------------------------------------------------------------------------------
4. EXPECTED RUNTIME
--------------------------------------------------------------------------------

    install.sh                              10 - 25 min   (dominated by the
                                                           ~600 MB download)
      of which: pip install                  1 -  3 min
                Bloom filter download       10 - 20 min

    claims/claim1_install/run.sh            20 - 60 sec
    claims/claim2_autoyara_preset/run.sh     1 -  3 min
    claims/claim3_augmented_preset/run.sh    1 -  4 min

    Total, excluding install.sh              3 -  8 min

Claim 1 alone is sufficient to confirm the installation is sound, and is the
recommended check during the "kick the tires" period.

Timings are for the reference platform above and scale with core count and
disk speed. Every claim uses a small synthetic corpus and is deliberately
sized to complete in minutes; none of them is a long-running experiment.

--------------------------------------------------------------------------------
5. NETWORK ENDPOINTS CONTACTED
--------------------------------------------------------------------------------

install.sh reaches out to:

    pypi.org                    Python dependencies
    github.com                  Bloom filter data, from the data-branch of
                                https://github.com/Botacin-s-Lab/AutoPYaraPyPI

The claims themselves run entirely offline once install.sh has completed.
